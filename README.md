# KeepEssence extension

KeepEssence 的浏览器扩展：把网页、文字、图片存进来。
The KeepEssence browser extension: save pages, text and images.

状态：还没开工。

## 它做什么

- 攒存当前网页、选中的文字、图片，得到一句结果。
- 只有「只存入」档的权限：看不到任何已存的内容，不收通知。
- 接入用短码：扩展显示一个短码，你在一台管理档的设备上核对后点允许。界面上不出现凭据。

攒存的契约只有两样：授权、保存。
